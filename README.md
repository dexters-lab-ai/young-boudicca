# Boudi AI - The Warrior Queen of the Digital Age

Boudi AI is a next-generation, multimodal AI companion application that blends a viral meme persona with cutting-edge generative AI technology. It features "Young Boudicca," a virtual being inspired by the trending Scottish teenager, who can see, hear, and speak, offering users a dynamic and engaging way to generate AI art, create memes, and get live data from the crypto world.

This project serves as a proof-of-concept for a new meta in virtual characters: **Personified AI Agents**. It demonstrates how combining a compelling narrative with powerful AI tools can create an experience that is more than just a utility—it's an alliance.

## ✨ Core Features

-   **Multimodal Interaction:** Chat with Boudicca via text or voice. She understands and responds in both text and high-quality voice, powered by the Gemini Live API for real-time conversation.
-   **Dynamic 3D Avatar:** Interact with a fully animated 3D character model that features realistic lip-syncing, facial expressions, and idle animations, bringing the persona to life.
-   **AI-Powered Image Styling:** Upload a photo or use your webcam to have Boudicca transform it into various artistic styles using image-to-image generation.
-   **Live Crypto Data Ticker:** A continuously scrolling marquee at the top of the UI displays live market data for trending, bonding, and graduated Solana tokens, fetched from the Solscan API.
-   **Meme Generator:** Create witty, shareable crypto memes with custom captions generated by AI.
-   **Dual AI Agents:** Seamlessly switch between the voice-driven, rebellious **Boudicca** and her analytical, text-only sister agent, **Eliza**, for different interaction styles.
-   **Centralized Crypto Tools:** Access all Solana data tools (Trending, Latest, Bonding, Graduated) from a single, convenient filter panel.
-   **Google Search Integration:** Boudicca can perform live Google searches to answer questions about current events and cite her sources directly in the chat.

## 🤖 The Personas

-   **Young Boudicca:** A fierce, 16-year-old Scottish warrior from Glasgow. She's a crypto-anarchist who sees decentralization as the ultimate rebellion against the "fiat Romans." She's sassy, protective, and armed with a sharp wit.
-   **Eliza:** Boudicca's sister. An analytical, data-driven AI agent who communicates exclusively through text. She provides concise, professional insights for crypto traders, acting as a calm counterpart to Boudicca's fiery personality.

## 🛠️ Technology Stack

-   **Frontend:** React, TypeScript, Vite, Three.js / React Three Fiber (for 3D rendering).
-   **AI & Generative Models:**
    -   **@google/genai (Gemini API):**
        -   `gemini-live-2.5-flash-preview-native-audio-dialog`: Powers the real-time, text-and-voice conversation with Boudicca.
        -   `gemini-2.5-flash`: Used for text generation, meme captions, and Google Search grounding.
        -   `gemini-2.5-flash-image-preview`: For all image-to-image styling and manipulation.
-   **3D Avatars:** VRM models with animations handled by `@pixiv/three-vrm`.
-   **State Management:** Zustand for simple, effective global state.
-   **Backend (Serverless Proxy):** A lightweight Node.js server using Express and `tsx` for proxying requests to the Solscan API, protecting sensitive keys.
-   **Styling:** Custom CSS with a futuristic, cyberpunk aesthetic.

## 🚀 Running Locally

**Prerequisites:** Node.js v18+

1.  **Clone the repository:**
    ```bash
    git clone https://github.com/your-username/boudi-ai.git
    cd boudi-ai
    ```

2.  **Install dependencies:**
    ```bash
    npm install
    ```

3.  **Set up your API Key:**
    -   Create a file named `.env` in the root of the project.
    -   Add your Google Gemini API key to this file (see `INSTRUCTIONS.md` for details):
        ```
        GEMINI_API_KEY="YOUR_API_KEY_HERE"
        ```

4.  **Run the application:**
    -   The app includes a server for proxying API calls and a frontend client. The `dev:all` script runs both concurrently.
    ```bash
    npm run dev:all
    ```

    Your application will be running at `http://localhost:5173`. The server runs on port `3001`.
